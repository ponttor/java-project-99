## About

Task Manager is a web application for organizing team workflows in one place. Users can create and assign tasks, manage workflow statuses, group work with labels, and quickly find tasks using filters.

## Tech stack

Java 21, Spring Boot 4, Spring MVC, Spring Data JPA, Hibernate, Spring Security with JWT, PostgreSQL, H2, Gradle, OpenAPI/Swagger UI, Sentry, JUnit, MockMvc, Docker, and Render.
